AI 智能层 - AI Intelligence Layer
DeepSeek API 集成
OpenAI SDKAsyncOpenAI
  • 简历解析 → 结构化 JSON
  • 简历分析 → 评分 + 优劣点 + 岗位匹配
  • 智能出题 → 根据简历 + 岗位 + 难度
  • 实时评分 → 流式评价 + 结构化分数
  • 综合报告 → 总分 + 维度分 + 建议
流式响应 (SSE Streaming)
StreamingResponseAsync Generator
  • 后端: async generator → yield data: {json}\n\n
  • 前端: native fetch + ReadableStream
  • 实时逐字显示 AI 评语
  • 过滤 JSON 评分块避免展示生数据
  • 作答中"思考中"动画效果
Prompt 工程
System PromptStructured Output
  • 简历解析: 强制 JSON 格式输出
  • 出题: 根据岗位类型动态调整难度
  • 评分: 先自然语言评语 → 再 JSON 分数
  • 上下文: 最后 6 轮对话截断控制 token
  • 区分实习/正式 岗位类型
