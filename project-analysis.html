2 应用场景 Application Scenarios
场景1 求职者面试模拟训练
  • 求职者注册、上传简历、获得AI简历分析
  • 选择目标岗位和难度，AI根据简历内容生成个性化面试题
  • 进行多轮仿真面试，AI实时流式评分反馈
  • 获得完整评估报告（总分、维度分、优势劣势、录用建议）

目标用户：程序员、产品经理、设计师等求职者

场景2 校招生/实习生面试准备
  • 系统检测"实习/intern"关键词，自动调整评估标准
  • 不因缺乏工作经验扣分，侧重基础和潜力
  • 出题难度自动降低，聚焦基础知识考核

目标用户：应届生、实习生候选人

场景3 资深人士高阶面试模拟
  • 岗位匹配更高难度题目（系统设计、性能优化、架构决策）
  • 更严格的评分标准，强调生产经验和深度
  • 全链路技术面试模拟

目标用户：高级/资深工程师

场景4 HR/招聘方平台管理
  • 查看平台整体使用数据统计
  • 管理用户账户（启用/禁用）
  • 查看所有面试记录和详情
  • 审查AI评估结果和完整对话记录

目标用户：HR、管理员、平台运营

场景5 纯简历质量评估
  • 不上传岗位也可以做简历分析
  • AI评估简历综合质量、技能匹配度
  • 输出优势/劣势/改进建议

目标用户：所有需要简历优化的用户

场景6 多岗位多轮面试对比
  • 针对同一份简历可创建多次面试
  • 换不同岗位/不同难度对比表现
  • 通过仪表盘管理所有历史面试

目标用户：海投型求职者

4 关键实现原理 Implementation Details

4.1 认证体系：双Token + 双Scope

Access Token（30分钟有效）：包含 user_id、email、scope 字段，HS256签名。每次请求校验签名和scope即可，无需查库。
Refresh Token（7~30天有效）：bcrypt哈希后存入 tokens 表，使用时查库比对哈希值。
Scope隔离：客户端JWT scope="client"，后台JWT scope="backoffice"，防止越权。
步骤说明
登录验证密码 → 签发双Token → 哈希RefreshToken存库
请求Axios拦截器附加 Bearer Access Token
校验verify_token() 校验签名+scope+有效期
过期401 → 用RefreshToken换新AccessToken
登出标记RefreshToken失效 → 清除前端token

4.2 简历处理流水线

上传PDF → pdfplumber逐页提取文本 → AI解析（DeepSeek输出结构化JSON：姓名/学历/技能/经历/项目/总结）→ AI分析（DeepSeek输出评估JSON：总分/匹配技能/缺失技能/优势/劣势/建议）→ 前端轮询状态（每2秒，最多30次，含动画进度条）

自适应评估：检测目标岗位是否含"实习/intern"关键词 → 调整AI Prompt中评估标准，实习岗不因无工作经历扣分

4.4 SSE 流式评分 —— 核心创新

后端实现

# interview_service.py
async def submit_answer_stream(interview_id, answer, user):
    # 1. 保存候选人作答到DB
    await save_candidate_message(...)

    # 2. 异步生成器：流式调用AI
    async def generate():
        async for chunk in ai_service.evaluate_answer_stream(...):
            yield f"data: {json.dumps({'type':'chunk','content':chunk})}\n\n"

        # 3. 流结束后提取分数，保存到DB
        score = extract_score(full_text)
        await update_message_score(...)

        # 4. 生成下一题或结束
        if not is_last:
            next_q = next_question(...)
            yield f"data: {json.dumps({'type':'done','next_question':next_q})}\n\n"
        else:
            report = await generate_report(...)
            yield f"data: {json.dumps({'type':'done','is_finished':True,'report':report})}\n\n"

    return StreamingResponse(generate(), media_type="text/event-stream")

前端实现

// interview.js
async function submitAnswerStream(interviewId, answer, { onChunk, onDone }) {
    const res = await fetch(`/api/v1/interviews/${interviewId}/answer/stream`, {
        method: 'POST',
        body: JSON.stringify({ answer }),
        headers: { 'Authorization': `Bearer ${token}` }
    })

    const reader = res.body.getReader()
    let buffer = ''
    const decoder = new TextDecoder()

    while (true) {
        const { done, value } = await reader.read()
        if (done) break
        buffer += decoder.decode(value, { stream: true })

        // 按 \n\n 分割SSE事件
        const parts = buffer.split('\n\n')
        buffer = parts.pop()

        for (const part of parts) {
            const lines = part.split('\n')
            for (const line of lines) {
                if (line.startsWith('data: ')) {
                    const data = JSON.parse(line.slice(6))
                    if (data.type === 'chunk') {
                        // 实时过滤JSON块，防止显示原始分数数据
                        onChunk(filterJsonBlocks(data.content))
                    } else if (data.type === 'done') {
                        onDone(data)
                    }
                }
            }
        }
    }
}
关键技术点：① ReadableStream 逐块读取避免阻塞 ② buffer 残差处理解决TCP分片问题 ③ 前端实时过滤JSON分数块避免视觉污染 ④ 流结束统一保存DB确保数据一致性

4.5 评分与报告生成

逐题评分

  • AI评估每题答案（结合简历背景 + 题目要求）
  • 输出：score(0-10) + feedback + follow_up标志
  • 评分Prompt先输出自然语言评语 → 再输出JSON分数

综合报告

  • overall_score = round(所有单题分平均, 1)
  • AI生成：summary / strengths / weaknesses / suggestions / hire_recommendation
  • 逐题分由Service层计算（不用AI）保证精确
